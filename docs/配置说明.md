# 配置说明

本文说明 `config.example.yaml` 的主要字段。首次部署时复制模板为 `config.yaml`，再填写企业微信、模型和 Redis 等真实配置。

```bash
cp config.example.yaml config.yaml
```

`config.yaml` 通常包含密钥和内网地址，不建议提交到 GitHub。

## 顶层结构

- `wechat`：企业微信企业、应用、回调、代理和消息去重配置。
- `api_keys`：模型供应商 API Key。
- `models`：OpenAI-compatible 模型配置。
- `redis`：Redis / Redis Stack 连接配置。
- `deployment`：服务端口、域名和媒体访问地址。
- `logging`：日志输出配置。
- `scheduler`：内置定时任务配置。

## 企业微信应用

每个企业微信自建应用写在 `wechat.agents` 下，key 使用应用 ID 字符串：

```yaml
wechat:
  corp_id: "YOUR_CORP_ID"
  agents:
    "1000001":
      name: "系统演示"
      agent_id: 1000001
      corp_secret: "YOUR_CORP_SECRET"
      token: "YOUR_TOKEN"
      encoding_aes_key: "YOUR_ENCODING_AES_KEY"
      plugins:
        - demo_conversation
      fetch_user_info: false
      include_time_info: true
```

字段说明：

- `corp_id`：企业微信企业 ID。
- `corp_secret`：当前应用 Secret。
- `token`：企业微信回调 Token。
- `encoding_aes_key`：企业微信回调 EncodingAESKey。
- `plugins`：当前应用启用的 Agent 插件列表。
- `fetch_user_info`：是否在处理消息前获取企业微信用户信息。
- `include_time_info`：是否向 Agent 注入当前时间上下文。

当前仓库内置两个 Agent 插件：

- `demo_conversation`：系统演示、插件列表、上下文摘要和基础工具。
- `schedule_manager`：自然语言创建、查询、删除和修改提醒。

## 模型配置

模型使用 `langchain-openai` 的 OpenAI-compatible 接口。API Key 建议统一放在 `api_keys`，再由 `models.<profile>.api_key_config` 引用。

```yaml
api_keys:
  dashscope: "YOUR_DASHSCOPE_API_KEY"
  ark: "YOUR_ARK_API_KEY"

models:
  dashscope:
    model: "qwen-plus"
    base_url: "https://dashscope.aliyuncs.com/compatible-mode/v1"
    api_key_config: "dashscope"
    api_key_env: "DASHSCOPE_API_KEY"

  ark:
    model: "doubao-1-5-pro-256k-250115"
    base_url: "https://ark.cn-beijing.volces.com/api/v3"
    api_key_config: "ark"
    api_key_env: "ARK_API_KEY"
```

Agent 插件可以在自己的 `agent_config.yaml` 中通过 `model_profile` 选择模型配置。

## Redis

Redis 用于：

- LangGraph checkpoint / 短期记忆。
- APScheduler jobstore 和 leader lock。
- 提醒任务等业务数据。

LangGraph Redis checkpoint 需要 Redis Stack 能力，建议使用 `docker-compose.yml` 中的 `redis-stack` 服务。

```yaml
redis:
  host: "redis-stack"
  port: 6379
  password: null
  db: 0
```

## 定时任务

`scheduler.tasks` 只配置内置任务。当前保留：

- `morning`：早安消息。
- `today_60s`：每日 60 秒图片消息。

```yaml
scheduler:
  test: false
  tasks:
    morning:
      time: "08:30"
      day_of_week: "*"
      users:
        - "user1"

    today_60s:
      time: "09:50"
      day_of_week: "*"
      users:
        - "user1"
```

用户通过 `schedule_manager` 创建的提醒不写在这里，会由工具写入 Redis 并注册到 APScheduler。

## 回调与健康检查

启动服务后：

- 健康检查：`GET /health`
- 企业微信回调：按企业微信后台配置到当前服务的对应应用回调地址。

Docker 默认启动命令：

```bash
uvicorn app.main:app --host 0.0.0.0 --port 4455
```
