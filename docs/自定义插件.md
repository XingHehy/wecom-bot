# Agent 插件与任务开发

wxbot 当前使用 `app/` 包作为运行时代码目录。对话能力通过 `app/agent_plugins/` 下的 Agent 插件扩展，定时任务通过 `app/tasks/` 注册。

## Agent 插件结构

每个 Agent 插件是一个独立目录：

```text
app/agent_plugins/my_agent/
  __init__.py
  agent_config.yaml
  tools.py
  logic.py
```

当前仓库内置：

- `demo_conversation`
- `schedule_manager`

## agent_config.yaml

示例：

```yaml
key: my_agent
name: 我的 Agent
display_name: 我的 Agent
description: 一个自定义 Agent 示例
status: enable
category: utility
model_profile: dashscope
model: qwen-plus
temperature: 0.3
max_tokens: 512
route_keywords:
  - 帮助
  - 查询
custom_tools:
  - my_tool
global_tools:
  - time_query
system_prompt: |
  你是一个企业微信 Agent。需要调用工具完成的事情必须调用工具。
```

字段说明：

- `key`：插件唯一标识，通常与目录名一致。
- `status`：`enable` / `disable`。
- `category`：插件分类，用于描述和兜底策略。
- `model_profile`：引用 `config.yaml` 中的 `models.<profile>`。
- `route_keywords`：进入模型前的关键词路由。
- `custom_tools`：当前插件 `tools.py` 里允许暴露给模型的工具。
- `global_tools`：共享工具，例如 `time_query`、`help_text`。
- `system_prompt`：Agent 系统提示词。

## 自定义工具

`tools.py` 需要实现 `build_tools`：

```python
def build_tools(*, agent_id: str, user_id: str, enabled_tools: list[str]):
    from langchain_core.tools import tool

    @tool
    def my_tool(text: str) -> str:
        """工具说明会提供给模型，用来判断何时调用。"""
        return f"收到：{text}"

    all_tools = [my_tool]
    return [item for item in all_tools if item.name in enabled_tools]
```

工具只在 Agent 被选中后可用。是否调用工具、调用哪个工具，由 LangChain Agent 根据用户输入和 `system_prompt` 决定。

## 路由逻辑

默认路由使用 `route_keywords`。当一个企业微信应用启用多个插件时，Runtime 会先计算关键词命中分数，再把消息交给得分最高的 Agent。

需要更复杂的规则时，可以在 `logic.py` 中实现：

```python
def route_score(message_text: str, profile) -> int:
    if "我的关键词" in message_text:
        return 10
    return 0
```

流程可以理解为：

```text
企业微信消息 -> Runtime 选择 Agent -> Agent 决定是否调用工具 -> 返回企业微信消息
```

## 启用插件

在 `config.yaml` 的目标企业微信应用下配置：

```yaml
wechat:
  agents:
    "1000001":
      plugins:
        - demo_conversation
        - my_agent
```

`plugins` 表示启用哪些 Agent 插件；工具绑定不写在这里，而是写在插件自己的 `agent_config.yaml`。

## 自定义定时任务

任务文件放在 `app/tasks/`，使用 `app.scheduler.task_registry.scheduled_task` 注册。

```python
from typing import List

from app.scheduler.task_registry import scheduled_task


@scheduled_task(key="daily_ping", mode="batch", default_time="09:00")
def send_daily_ping(user_ids: List[str]):
    for user_id in user_ids:
        print(f"send message to {user_id}")
```

配置中加入同名任务：

```yaml
scheduler:
  tasks:
    daily_ping:
      time: "09:00"
      day_of_week: "*"
      users:
        - "user1"
```

任务模式：

- `mode="batch"`：任务函数一次收到用户列表。
- `mode="per_user"`：框架为每个用户单独创建 job。

当前公开版本只内置 `morning` 和 `today_60s` 两个任务。
