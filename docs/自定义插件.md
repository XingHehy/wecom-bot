# 自定义插件与定时任务开发指南

本文档介绍如何在本项目中新增：

1. 自定义消息插件（`plugins/`）
2. 自定义定时任务（`tasks/`）

## 一、如何自定义插件

### 1.1 插件位置与命名

- 文件放在 `plugins/` 根目录（当前插件加载器扫描该目录一级 `.py` 文件）。
- 文件名建议语义化，例如：`plugins/weather_notice.py`。
- 类名建议以 `Plugin` 结尾，例如：`WeatherNoticePlugin`。

### 1.2 插件基类接口

插件需继承 `core.plugin.Plugin`，常用方法：

- `handle(message, from_user, context)`：处理消息并返回回复；不处理时返回 `None`。
- `get_commands()`：返回可展示的命令列表。
- `supports_message_type(message_type)`：按需限制消息类型（默认仅文本）。

### 1.3 最小插件示例

```python
from typing import Any, Dict, List, Optional, Union

from core.plugin import Plugin


class HelloPlugin(Plugin):
    def __init__(self):
        super().__init__(name="问候插件", description="一个最小可用插件示例")

    async def handle(
        self, message: Union[str, Dict[str, Any]], from_user: str, context: Dict[str, Any]
    ) -> Optional[str]:
        if isinstance(message, str) and message.strip() in ["hello", "你好"]:
            return "你好，我是自定义插件。"
        return None

    def get_commands(self) -> List[str]:
        return ["hello - 返回问候语"]
```

### 1.4 启用插件

在 `config.yaml` 的目标应用下，添加插件文件名（不带 `.py`）：

```yaml
wechat:
  agents:
    "1000001":
      plugins: ["schedule_manager", "hello"]
```

> 上例中，`hello` 对应 `plugins/hello.py`。

### 1.5 开发建议

- 插件尽量无状态，状态数据放 Redis。
- 对外部 API 调用加超时和异常处理。
- 对非目标消息尽快 `return None`，避免影响其他插件处理。

## 二、如何自定义定时任务

### 2.1 任务位置与注册方式

- 文件放在 `tasks/` 目录。
- 使用 `core.task_registry.scheduled_task` 装饰器注册任务。
- 任务 key 必须与 `config.yaml -> scheduler.tasks.<key>` 对应。

### 2.2 任务模式说明

- `mode="batch"`：任务函数参数是 `List[str]`（用户列表），一次执行可批量发送。
- `mode="per_user"`：任务函数参数是 `str`（单个用户），框架会为每个用户建一个 job。

### 2.3 最小定时任务示例

```python
import asyncio
from typing import List

from core.task_registry import scheduled_task
from core.wecom.enterprise_wechat import enqueue_active_message


@scheduled_task(key="daily_ping", mode="batch", default_time="09:00")
def send_daily_ping(user_ids: List[str]):
    if not user_ids:
        return
    touser = "|".join([u for u in user_ids if u])
    if not touser:
        return
    asyncio.run(
        enqueue_active_message(
            agent_id="1000001",
            msg="这是一条自定义定时任务消息",
            user=touser,
        )
    )
```

### 2.4 启用定时任务

在 `config.yaml` 中新增对应任务配置：

```yaml
scheduler:
  tasks:
    daily_ping:
      time: "09:00"
      day_of_week: "*"
      users: ["user1", "user2"]
```

字段说明：

- `time`：执行时间，格式 `HH:MM`
- `day_of_week`：星期配置，`"*"` 表示每天；也可用 `[1,2,3,4,5]`
- `users`：接收用户列表（企业微信 userid）

## 三、联调与排查建议

- 修改 `plugins/` 或 `tasks/` 后重启服务，确认加载日志。
- 若任务未触发，先检查：
  - `scheduler.tasks.<key>` 是否存在
  - key 是否与 `@scheduled_task(key="...")` 一致
  - 时间格式是否正确（`HH:MM`）
- 若插件无响应，先确认：
  - 是否已加入目标应用 `plugins`
  - `handle` 是否命中触发条件
  - 是否被 `supports_message_type` 过滤
