# 企业微信应用配置说明

本文用于指导如何在企业微信后台创建自建应用，并把它接入 wxbot。

## 创建应用

1. 打开企业微信管理后台应用页面：  
   [https://work.weixin.qq.com/wework_admin/frame#/apps](https://work.weixin.qq.com/wework_admin/frame#/apps)
2. 新增一个自建应用，填写应用名称和可见范围。
3. 创建完成后记录 `AgentId` 和 `Secret`，后续写入 `config.yaml`。

![创建应用](./images/1.png)

## 配置接收消息

在应用详情页开启「接收消息」，准备以下参数：

- `Token`
- `EncodingAESKey`
- 回调 URL

推荐回调 URL 使用你的公网服务地址，并按项目实际路由填写。例如：

```text
https://your-domain.com/1000001/callback
```

其中 `1000001` 是企业微信应用的 `agent_id`。

![接收消息配置](./images/2.1.png)

## 填写项目配置

把企业微信后台的信息填入 `config.yaml`：

```yaml
wechat:
  corp_id: "YOUR_CORP_ID"
  agents:
    "1000001":
      name: "系统演示"
      agent_id: 1000001
      corp_secret: "YOUR_CORP_SECRET"
      token: "YOUR_TOKEN"
      encoding_aes_key: "YOUR_ENCODING_AES_KEY"
      plugins:
        - demo_conversation
      fetch_user_info: false
      include_time_info: true
```

如果你要让应用处理提醒消息，可以启用 `schedule_manager`：

```yaml
plugins:
  - demo_conversation
  - schedule_manager
```

`plugins` 表示当前企业微信应用启用哪些 Agent 插件。工具绑定在插件目录的 `agent_config.yaml` 中配置。

## OAuth、可信域名和可信 IP

如果使用网页授权或需要企业微信接口可信 IP，请在企业微信后台配置：

- OAuth 回调域名
- JS-SDK 可信域名
- 企业可信 IP

对应项目配置：

```yaml
wechat:
  oauth:
    callback_domain: "https://your-domain.com"
    callback_domains:
      - "https://your-domain.com"

deployment:
  domain: "your-domain.com"
  media_url_base: "https://your-domain.com"
```

如果服务在本地或出口 IP 不固定，可以配置代理：

```yaml
wechat:
  proxy: "s5://user:password@host:port"
```

## 验证

1. 启动服务：

```bash
uvicorn app.main:app --host 0.0.0.0 --port 4455
```

2. 访问健康检查：

```text
https://your-domain.com/health
```

3. 在企业微信后台点击「验证 URL」。
4. 给应用发送消息，例如：

```text
系统状态
明天 9 点提醒我开会
```

如果 `demo_conversation` 和 `schedule_manager` 都已启用，系统类消息会进入 demo Agent，提醒类消息会进入 schedule Agent。
