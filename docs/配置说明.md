# `config.example.yaml` 使用指南

## 1. 基本使用流程

1. 复制模板：

```bash
cp config.example.yaml config.yaml
```

2. 按下面字段说明填写真实配置（企业微信后台参数、Redis、域名等）。
3. 启动服务后，企业微信回调地址指向你的服务地址。

## 2. 顶层字段说明

- `wechat`：企业微信相关配置（企业 ID、应用、OAuth、消息去重）。
- `api_keys`：大模型 API Key（给 AI 对话插件使用）。
- `redis`：Redis 连接配置（用于会话、调度、状态存储）。
- `deployment`：服务监听端口和部署域名。
- `logging`：日志输出与滚动策略。
- `scheduler`：定时任务总开关与任务列表。

## 3. `wechat` 字段说明

- `wechat.corp_id`：企业微信企业 ID（CorpID）。
- `wechat.proxy`：统一代理配置（可选），支持 `http://` 或 `s5://` 前缀。  
  适用场景：如果你把服务部署在本地家宽环境，公网出口 IP 可能经常变化，而企业微信相关接口在某些场景下需要`可信 IP`才能正常发送，这时建议配置一个固定出口 IP 的代理。  
  如果服务部署在云服务器且出口公网 IP 固定，通常可以不配置该项。
- `wechat.debug`：调试开关，开启后会输出更多调试日志。
- `wechat.enable_msg_dedup`：是否启用消息去重，建议 `true`。
- `wechat.msg_dedup_ttl`：去重标记有效期（秒），防止回调重放。
- `wechat.oauth.callback_domain`：全局 OAuth 回调域名（需与企业微信后台一致）。
- `wechat.oauth.callback_domains`：可选的回调域名列表。

### `wechat.agents`（多应用配置）

`agents` 的 key 是应用 ID 字符串（如 `"1000001"`），每个应用包含：

- `name`：应用名称（可选，但建议填写，便于排查日志）。
- `agent_id`：应用 ID（数字）。
- `corp_secret`：该应用的 Secret。
- `token`：企业微信回调 Token。
- `encoding_aes_key`：企业微信回调加密 Key。
- `plugins`：该应用启用的插件列表。
  - 示例：`["schedule_manager"]` 或 `["ai_chat_demo"]`
- `oauth.callback_domain`：应用级回调域名（可覆盖全局配置）。

## 4. `api_keys` 字段说明

- `api_keys.dashscope`：通义模型 API Key。
- 仅在启用 AI 插件（如 `ai_chat_demo`）时必填；只用定时任务可先留空。

## 5. `redis` 字段说明

- `redis.host`：Redis 主机地址。
- `redis.port`：Redis 端口。
- `redis.password`：Redis 密码（无密码可留空或删除）。
- `redis.db`：Redis DB 编号（通常为 `0`）。

## 6. `deployment` 字段说明

- `deployment.port`：服务端口（与启动访问端口一致）。
- `deployment.domain`：对外访问域名（OAuth/媒体链接会用到）。

## 7. `logging` 字段说明

- `logging.level`：日志级别（`DEBUG`/`INFO`/`WARNING`/`ERROR`）。
- `logging.console`：是否输出到控制台。
- `logging.file`：是否写入日志文件。
- `logging.max_size`：单个日志文件最大大小（如 `10MB`）。
- `logging.backup_count`：日志滚动保留数量。

## 8. `scheduler` 字段说明

- `scheduler.test`：是否开启调度器测试任务（每分钟一次）。
- `scheduler.tasks`：任务清单，key 对应任务代码里 `@scheduled_task(key="...")` 的 key。

当前示例中包含：

- `demo`
  - `time`：执行时间（`HH:MM`）
  - `users`：接收用户列表（企业微信 userid）
- `today_60s`
  - `time`：执行时间（`HH:MM`）
  - `users`：接收用户列表（企业微信 userid）

## 9. 最小可用示例

如果你只想先跑通，可先配置：

- 一个 `schedule_manager` 应用（`wechat.agents`）
- `redis` 连接
- `deployment.port`
- `scheduler.tasks.demo`

这样可以先验证 Webhook 与定时任务链路，再逐步补充 AI 插件和更多应用。
